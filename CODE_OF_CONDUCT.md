# Code of Conduct

We want this project to be a welcoming place to report problems, exchange ideas
and contribute improvements. Everyone participating in project issues, pull
requests and other project spaces is expected to follow this code of conduct.

## Expected behavior

- Treat others with respect, regardless of background, identity or experience.
- Give constructive feedback about the work and accept feedback respectfully.
- Discuss technical disagreements with evidence and assume good intentions.
- Respect other people's privacy and the time of contributors and maintainers.

## Unacceptable behavior

- Harassment, discrimination, threats, insults or personal attacks.
- Sexual harassment or unwelcome sexual attention.
- Publishing private information or credentials without permission.
- Trolling, spam or repeated disruption of project discussions.
- Retaliation against someone who reports a concern.

## Reporting concerns

Report concerns to the maintainer, **Mayuran Asairatnam**, using a private
contact method listed on the maintainer's GitHub profile, if available. If no
private contact method is available, open an issue asking for a private way to
report a conduct concern. Do not include sensitive details or identify affected
people in that public request.

Maintainers should handle reports discreetly and share details only as needed
to investigate and respond. Absolute confidentiality cannot be guaranteed.

## Enforcement

Maintainers review reports in context and may request a change in behavior,
remove inappropriate content, close or lock discussions, or temporarily or
permanently restrict participation. The response should reflect the severity
and repetition of the behavior. Maintainers are expected to follow this code
of conduct as well.
